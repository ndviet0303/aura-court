## Acceptance protocol

For each row record test command, environment, outcome, persisted record assertions and failure evidence. Include validation errors, tenant/role denial, reload after success, and applicable race/retry. API-mocked component tests cannot satisfy real-API acceptance. Provider sandbox, load and recovery gates require their own execution records; missing credentials or evidence remain blocked rather than passed. Existing localization/theme/API-alignment behavior must remain covered by the frontend regression suite.
